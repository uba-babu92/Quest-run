# Quest Run

**Cours. Explore. Collectionne.**

Chaque semaine, des quêtes t'envoient vers de vrais lieux de ta ville. Cours jusqu'au lieu, valide avec le GPS, prends ta photo : elle devient une carte de ta collection.

Appli : https://uba-babu92.github.io/quest-run/

Sur iPhone : ouvrir le lien dans Safari → Partager → **Sur l'écran d'accueil**.
